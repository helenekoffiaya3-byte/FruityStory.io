FS LIVE DEVELOPER API

FruityStory Developer Platform

FS Live est le format de clé API de production de FruityStory : fs_live_.... Les secrets complets sont générés côté serveur, hachés avec SHA-256 dans Netlify Blobs et ne sont jamais renvoyés après leur création.

🔑 Générer une clé FS Live

POST/api/developer/keys

X-User-Id: TON_ID_DE_COMPTE
Content-Type: application/json

{"name":"Mon application"}

Réponse : la clé secrète complète est affichée une seule fois.

📋 Gérer les clés

GET/api/developer/keys — liste les clés et leur état.

DELETE/api/developer/keys/KEY_ID — révoque une clé.

POST/api/developer/keys/rotate/KEY_ID — révoque l'ancienne clé et génère immédiatement une nouvelle FS Live.

🎬 Génération vidéo

POST/api/developer/video/generate

Authorization: Bearer fs_live_VOTRE_CLE
Content-Type: application/json

{"prompt":"Une histoire cinématique avec des personnages-fruits","duration":15,"provider":"veo"}

Le serveur vérifie la clé, le solde de crédits, appelle le Provider API FruityStory et débite le coût configuré uniquement après acceptation du job.

💰 Payment API

POST/api/developer/payments/checkout

Authorization: Bearer fs_live_VOTRE_CLE
{"priceId":"price_xxx","mode":"payment"}

Le Price ID est contrôlé côté serveur. Le navigateur ne reçoit jamais la clé secrète Stripe.

POST/api/developer/payments/webhook — webhook Stripe signé et idempotent.
