API REFERENCE

Documentation développeur

Les endpoints publics utilisent une clé API. Les clés fournisseurs et les clés de paiement restent exclusivement dans les variables d'environnement serveur.

Génération vidéo

POST/api/video/generate

{"prompt":"...","duration":15,"provider":"auto"}

Statut d'une génération

GET/api/video/status?id=JOB_ID

Paiement / checkout

POST/api/payments/checkout

{"priceId":"PRICE_ID","credits":5000,"successUrl":"https://fruitstory.io/success"}

Webhook paiement

POST/api/payments/webhook

Le webhook vérifie la signature du fournisseur avant de créditer le compte. Ne jamais faire confiance au montant envoyé par le navigateur.

Usage

GET/api/usage

Retourne la consommation vidéo, les crédits restants et les limites du plan.
