API REFERENCE

Developer API FruityStory

La plateforme développeur est reliée aux Functions Netlify. Les clés API sont hachées et stockées dans Netlify Blobs. Les clés fournisseurs et Stripe restent côté serveur.

Créer une clé API

POST/api/developer/keys

X-User-Id: TON_ID_DE_COMPTE
{"name":"Mon application"}

La clé secrète est affichée une seule fois.

Générer une vidéo

POST/api/developer/video/generate

Authorization: Bearer fs_live_...
{"prompt":"Une histoire cinématique avec des personnages-fruits","duration":15,"provider":"veo"}

La requête est transmise au Provider API interne et les crédits sont débités après acceptation de la génération.

Statut

GET/api/developer/video/status/JOB_ID

Crédits et usage

GET/api/developer/credits

GET/api/developer/usage

Paiement / Checkout

POST/api/developer/payments/checkout

Authorization: Bearer fs_live_...
{"priceId":"price_xxx","credits":5000,"mode":"payment"}

Le serveur crée la session Stripe. Le navigateur ne reçoit jamais la clé secrète Stripe.

Webhook paiement

POST/api/developer/payments/webhook

Stripe signe le webhook. Après vérification de la signature, les crédits du compte sont ajoutés et l'événement est rendu idempotent.

Fournisseurs

GET/api/developer/providers

Expose les capacités disponibles sans révéler les secrets : Google Veo et PixVerse.

Exemple cURL

curl -X POST https://api.fruitystory.io/api/developer/video/generate \
  -H "Authorization: Bearer fs_live_VOTRE_CLE" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"Un drama fruitier cinématique","duration":15,"provider":"veo"}'
