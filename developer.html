Exemple d'appel vidéo

curl -X POST https://api.fruitystory.io/api/developer/video/generate \
  -H "Authorization: Bearer fs_live_VOTRE_CLE" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"Une histoire cinématique avec des personnages-fruits","duration":15,"provider":"veo"}'

Architecture paiement

Le serveur crée la session Stripe à partir d'un Price ID autorisé et d'une table serveur Price → crédits. Le navigateur ne peut pas choisir librement le nombre de crédits. Les crédits ne sont ajoutés qu'après vérification de la signature du webhook Stripe.

POST /api/developer/payments/checkout
POST /api/developer/payments/webhook
GET  /api/developer/credits
GET  /api/developer/usage
