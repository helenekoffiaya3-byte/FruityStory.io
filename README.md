# FruityStory.io

Interface web de création, génération, édition et préparation à la publication de vidéos.

## Structure

- `index.html` — interface principale
- `styles.css` — styles responsive
- `app.js` — interactions côté navigateur
- `netlify.toml` — configuration de déploiement Netlify

## Déploiement

Le projet est une interface statique compatible avec Netlify. Les secrets et clés API ne doivent pas être placés dans les fichiers publics du dépôt.
