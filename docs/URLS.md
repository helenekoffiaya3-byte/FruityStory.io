# FruityStory.io — Répertoire des URL

Ce document centralise les principales URL publiques de FruityStory.io.

> **Domaine public actuel :** `https://fruitystory-io.netlify.app`
>
> Il s'agit de l'URL gratuite fournie par Netlify. Les URL du site utilisent ce domaine tant qu'un domaine personnalisé n'est pas configuré.

## Important

Les chemins ci-dessus correspondent aux pages publiques prévues par le projet. Les fichiers du backend, les fichiers `.env`, les secrets, les configurations internes et les endpoints privés ne doivent pas être exposés dans le sitemap public.

Si un domaine personnalisé est configuré plus tard, remplacer le domaine Netlify par le domaine réellement configuré et vérifier chaque URL avec le déploiement final.
