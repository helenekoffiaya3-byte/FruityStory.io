# FruityStory.io — Répertoire des URL

Ce document centralise les principales URL publiques de FruityStory.io.

> Domaine de production prévu : `https://fruitystory.io`
>
> Les URL de fichiers HTML peuvent être utilisées directement sur un hébergement statique compatible. Les routes applicatives dynamiques doivent être activées par le serveur/deployment.

## Important

Les chemins ci-dessus correspondent aux pages publiques prévues par le projet. Les fichiers du backend, les fichiers `.env`, les secrets, les configurations internes et les endpoints privés ne doivent pas être exposés dans le sitemap public.

Lors du passage en production, remplacer le domaine provisoire par le domaine réellement configuré et vérifier chaque URL avec le déploiement final.
