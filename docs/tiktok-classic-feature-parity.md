# FruityStory.io — architecture fonctionnelle complète (référence TikTok classique)

> Objectif : reproduire les **capacités fonctionnelles publiquement documentées** d'une plateforme vidéo sociale moderne comparable à TikTok classique, sous la marque FruityStory.io. Ce document ne copie ni le code source, ni les assets, ni la marque, ni l'interface propriétaire de TikTok.
>
> Exclusion permanente : **LIVE et tous ses sous-systèmes** (LIVE gifts, diamonds, wallet LIVE, abonnements LIVE), ainsi que TikTok Shop et les systèmes de boutique. Les abonnements créateurs ne font pas partie du périmètre.

## 26. Règle d'implémentation
Tout élément ci-dessus doit être représenté dans FruityStory.io par une page, un panneau, une sous-page, une action, un état ou une API correspondante. Les fonctionnalités doivent être nommées et dessinées avec la marque FruityStory.io et son identité visuelle, sans reprendre les éléments propriétaires de TikTok.
